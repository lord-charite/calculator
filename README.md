
# Calculator

A simple calculator application for performing basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Installation

Clone the repository:
```bash
git clone https://github.com/lord-charite/calculator.git
cd calculator
```

## Usage

```bash
python calculator.py
```

Enter your numbers and select an operation when prompted.

## Requirements

- Python 3.7+
